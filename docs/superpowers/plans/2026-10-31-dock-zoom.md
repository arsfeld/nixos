# Dock Zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** macOS-style magnification on Pantheon's dock (`pantheon.elementary-dock` 8.3.3), carried as a local patch next to dock stacks and configured from `constellation.desktop.pantheon.dockZoom`.

**Architecture:** Zoom is the second feature in `modules/constellation/pantheon-dock/`, laid out exactly like `stacks/`: new Vala files in `zoom/src/` are copied to the dock's `src/Zoom/`, and `zoom/hooks.patch` holds the edits to upstream files, generated on top of `stacks/hooks.patch`. The Vala work happens in a local clone of `elementary/dock` whose base commit is 8.3.3 with stacks applied. Inside the dock, a pure `ZoomMath` namespace holds the falloff and pointer mapping (unit tested), a `ZoomController` owns state and easing, and `ItemGroup` places each item with a `Gtk.Fixed` child transform (translate plus scale about the item's bottom centre) and widens itself by the summed zoom extra, so the window widens through the existing `SizeGroup` path.

**Tech Stack:** Vala, GTK 4, libadwaita, meson; Nix overlays, NixOS dconf databases, NixOS VM tests (`testers.nixosTest`).

**Spec:** `docs/superpowers/specs/2026-10-31-dock-zoom-design.md`

**Read first:** `modules/constellation/pantheon-dock/CLAUDE.md` (visual testing loop, Vala lifetime traps, GTK 4.22 icon breakage) and `modules/constellation/pantheon-dock/default.nix`.

## Global Constraints

- Start only once the stacks work has landed: `stacks/hooks.patch` and `stacks/src/` are committed and no longer changing. If they change after Task 1 built the clone's base, rebuild the base (see "Development loop").
- Upstream base: `elementary/dock` tag `8.3.3`. If `nix eval --raw .#nixosConfigurations.raider.pkgs.pantheon.elementary-dock.version` no longer prints `8.3.3`, stop and rebase onto the new tag first.
- `pantheon-dock/default.nix` stays the only overlay of `elementary-dock`. Features apply in order: stacks, then zoom.
- Local patch only. Never open an upstream PR or offer one.
- Commit straight to `master` in `~/Code/nixos`; no branches or worktrees there. The dock clone is a separate scratch repo and is never pushed.
- Commit messages in `~/Code/nixos`: conventional commits, scope `modules`. Never mention Claude.
- New files in `~/Code/nixos` are invisible to `nix build` until `git add`ed (`git add -N` is enough).
- Settings: `zoom-enabled` (b, default `true`), `zoom-size` (i, default `84`).
- `zoom-size` clamp: `icon-size … icon-size + floor(64 × icon-size / (icon-size + 6))`, i.e. 48…104 at the default 48 px icons. An out-of-range value logs exactly one `warning ()` per settings change, with the text `zoom-size %d is outside %d…%d; using %d`.
- Falloff: cosine bell, 3 resting slots each side of the pointer, exactly 1.0 beyond.
- Ease in/out: 150 ms, `EASE_OUT_QUAD`.
- Zoom rests during any drag over the dock, and is frozen while an item's popover (not its tooltip) is open. Stack popovers count: `StackItem` parents its popover to itself.
- **A task that changes what the dock draws is not done until you have looked at it** on raider's live session with `just pantheon::dock-run` and `just pantheon::shot`, and read the PNG. Never inject input (no ydotool): open things through test hooks (`DOCK_ZOOM_AT`, added in Task 3; `DOCK_STACKS_OPEN` from stacks).
- Signal handlers on objects that outlive the call are methods, not lambdas capturing locals (`pantheon-dock/CLAUDE.md`).
- Run `just fmt` before committing Nix changes.

## Spec corrections, made in Task 5

1. **Patch location.** The spec puts the patch in `modules/constellation/desktop/`, which cannot exist (haumea: `directory 'desktop' conflicts with file 'desktop.nix'`). It goes in `modules/constellation/pantheon-dock/zoom/`, applied by `pantheon-dock/default.nix` after stacks. The option lives there too, next to `dockStacks`.
2. **Clamp.** The icon's 6 px top padding scales with it, so the largest size that fits the 64 px headroom is 104 at 48 px icons, not `icon-size + 64`.
3. **Mechanics.** Items are placed with `Gtk.Fixed.set_child_transform` instead of a width change on `BaseItem`. The workspace separator is not scaled. The dynamic "new workspace" item is wrapped in its own one-item `ItemGroup` so it zooms like the others.
4. **Tests.** The VM check is the existing stacks VM test, renamed `tests/pantheon-dock-test.nix`, with the zoom pinned through the `DOCK_ZOOM_AT` hook. No pointer injection.

```vala
/*
 * SPDX-License-Identifier: GPL-3.0
 */

/**
 * The dock zoom's arithmetic, kept free of GTK so it can be unit tested.
 */
namespace Dock.ZoomMath {
    /** How many resting slots on each side of the pointer the zoom reaches. */
    public const double RANGE = 3.0;

    /**
     * The zoom of an item whose resting centre is distance px from the
     * pointer: max_factor under the pointer, falling along a cosine bell to
     * exactly 1.0 at RANGE slots away.
     */
    public double factor (double distance, double slot, double max_factor) {
        var slots = Math.fabs (distance) / slot;
        if (slots >= RANGE) {
            return 1.0;
        }

        return 1.0 + (max_factor - 1.0) * (Math.cos (Math.PI * slots / RANGE) + 1.0) / 2.0;
    }

    /**
     * Maps a pointer x in the zoomed dock back to the resting dock. The
     * window is centred, so growing by n px moves its left edge n / 2 px left.
     */
    public double rest_x (double pointer_x, double zoomed_width, double rest_width) {
        return pointer_x - (zoomed_width - rest_width) / 2.0;
    }

    /**
     * The largest zoom-size whose scaled item still fits in headroom px above
     * the dock. item_height is the icon plus its top padding, which scales too.
     */
    public int max_zoom_size (int icon_size, int item_height, int headroom) {
        return icon_size + (int) Math.floor ((double) headroom * icon_size / item_height);
    }

    /** How far an item of item_height px rises when scaled by factor. */
    public double rise (int item_height, double factor) {
        return item_height * (factor - 1.0);
    }
}
```

`src/Zoom/ZoomController.vala`:

```vala
/*
 * SPDX-License-Identifier: GPL-3.0
 */

/**
 * Owns the dock's zoom: where the pointer is in resting coordinates, how far
 * the zoom has eased in, and the clamped peak factor from settings.
 */
public class Dock.ZoomController : Object {
    private const uint EASE_DURATION = 150;

    public signal void changed ();

    public Gtk.Widget widget { get; construct; }

    /** 0 at rest, 1 fully zoomed. */
    public double amount { get; private set; default = 0.0; }

    /** How far magnified icons rise above the dock while zoomed, for the input region. */
    public int input_rise {
        get { return amount > 0.0 ? max_rise : 0; }
    }

    private GLib.Settings settings;
    private Adw.TimedAnimation ease;
    private bool enabled;
    private double max_factor = 1.0;
    private int max_rise = 0;
    private double pointer_rest_x = 0.0;

    public ZoomController (Gtk.Widget widget) {
        Object (widget: widget);
    }

    construct {
        settings = new GLib.Settings ("io.elementary.dock");

        ease = new Adw.TimedAnimation (
            widget, 0, 1, EASE_DURATION,
            new Adw.CallbackAnimationTarget (on_ease)
        ) {
            easing = EASE_OUT_QUAD
        };

        settings.changed["zoom-enabled"].connect (update_settings);
        settings.changed["zoom-size"].connect (update_settings);
        settings.changed["icon-size"].connect (update_settings);
        update_settings ();
    }

    private void on_ease (double val) {
        amount = val;
        changed ();
    }

    private void update_settings () {
        enabled = settings.get_boolean ("zoom-enabled");

        var icon_size = settings.get_int ("icon-size");
        var item_height = icon_size + Launcher.PADDING;
        var max_size = ZoomMath.max_zoom_size (icon_size, item_height, MainWindow.TOP_MARGIN);
        var size = settings.get_int ("zoom-size");
        var clamped = size.clamp (icon_size, max_size);
        if (clamped != size) {
            warning ("zoom-size %d is outside %d…%d; using %d", size, icon_size, max_size, clamped);
        }

        max_factor = (double) clamped / icon_size;
        max_rise = (int) Math.ceil (ZoomMath.rise (item_height, max_factor));

        if (!enabled) {
            ease_to (0.0);
        }

        changed ();
    }

    public void pointer_moved (double rest_x) {
        pointer_rest_x = rest_x;
        if (enabled) {
            ease_to (1.0);
        }

        changed ();
    }

    public void pointer_left () {
        ease_to (0.0);
    }

    /** The zoom for an item whose resting centre is at rest_center. */
    public double factor_at (double rest_center) {
        if (amount <= 0.0) {
            return 1.0;
        }

        var peak = ZoomMath.factor (rest_center - pointer_rest_x, ItemManager.get_launcher_size (), max_factor);
        return 1.0 + (peak - 1.0) * amount;
    }

    private void ease_to (double target) {
        var playing = ease.state == Adw.AnimationState.PLAYING;
        if (ease.value_to == target && (playing || amount == target)) {
            return;
        }

        // reset () snaps amount back to the old value_from, so remember where we are.
        var from = amount;
        ease.reset ();
        ease.value_from = from;
        ease.value_to = target;
        ease.play ();
    }
}
```

```vala
    // Test hook for screenshot checks: with DOCK_ZOOM_AT=<slots>, the dock zooms
    // 1 s after it starts as if the pointer rested that many launcher widths from
    // its left edge, and stays zoomed until a real pointer enters and leaves it.
    // It fires before DOCK_STACKS_OPEN (1.5 s), so a stack popover opens on the
    // zoomed layout.
    private void maybe_zoom_for_test () {
        var wanted = Environment.get_variable ("DOCK_ZOOM_AT");
        if (wanted == null) {
            return;
        }

        var slots = double.parse (wanted);
        Timeout.add_once (1000, () => {
            message ("DOCK_ZOOM_AT: zooming at %g slots", slots);
            zoom.pointer_moved (slots * get_launcher_size ());
        });
    }

    private void update_pointer (double x) {
        if (drop_motion.contains_pointer || find_open_popover () != null) {
            return;
        }

        zoom.pointer_moved (ZoomMath.rest_x (x, get_width (), get_rest_width ()));
    }

    private void on_pointer_left () {
        var popover = find_open_popover ();
        if (popover == null) {
            zoom.pointer_left ();
            return;
        }

        // Hold the zoom while the popover is open, so its anchor does not slide away from it.
        if (popover != frozen_popover) {
            frozen_popover = popover;
            popover.closed.connect (on_frozen_popover_closed);
        }
    }

    private void on_frozen_popover_closed () {
        frozen_popover.closed.disconnect (on_frozen_popover_closed);
        frozen_popover = null;
        if (!motion.contains_pointer) {
            zoom.pointer_left ();
        }
    }

    private Gtk.Popover? find_open_popover () {
        for (var group = get_first_child (); group != null; group = group.get_next_sibling ()) {
            if (!(group is ItemGroup)) {
                continue;
            }

            for (var item = group.get_first_child (); item != null; item = item.get_next_sibling ()) {
                var popover = ((BaseItem) item).get_open_popover ();
                if (popover != null) {
                    return popover;
                }
            }
        }

        return null;
    }

    private static double get_child_rest_width (Gtk.Widget child) {
        if (child is ItemGroup) {
            return ((ItemGroup) child).rest_width;
        }

        if (!child.visible) {
            return 0.0;
        }

        // Includes margins, so the separator's spacing counts.
        int minimum, natural, minimum_baseline, natural_baseline;
        child.measure (HORIZONTAL, -1, out minimum, out natural, out minimum_baseline, out natural_baseline);
        return natural;
    }

    private double get_rest_width () {
        var width = 0.0;
        for (var child = get_first_child (); child != null; child = child.get_next_sibling ()) {
            width += get_child_rest_width (child);
        }

        return width;
    }

    private void queue_zoom () {
        if (zoom_tick_id != 0) {
            return;
        }

        zoom_tick_id = add_tick_callback (() => {
            zoom_tick_id = 0;
            apply_zoom ();
            return Source.REMOVE;
        });
    }

    private void apply_zoom () {
        var offset = 0.0;
        for (var child = get_first_child (); child != null; child = child.get_next_sibling ()) {
            if (child is ItemGroup) {
                ((ItemGroup) child).apply_zoom (zoom, offset);
            }

            offset += get_child_rest_width (child);
        }
    }
```
